A bold poster collage summing up the world news of Thursday 26 November 2026: a flat-illustration hero scene of a rocket rising past a space station above a crescent Earth for the day's space stories (Pakistan's first astronaut flying to Tiangong), under the headline "SPACE, TARIFFS AND A COURTROOM", with three captioned vignettes below — a factory for the planned new US tariffs, a gavel for the judge blocking Trump's birthright citizenship order, and a chess board for Game 2 of the World Chess Championship ending in a draw — plus a ticker of further stories from the day.

## Run it

```sh
python3 main.py
```

This writes `entry.png` (1024x1024) next to `main.py` and to `/output/entry.png`. It needs only Python 3 with Pillow, runs with no network, and is fully deterministic: two runs produce byte-identical files.
